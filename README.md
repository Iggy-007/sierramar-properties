# SierraMar Homes – property data

Data and images for sierramarhomes.com (Costa del Sol and Caribe pages).

- `data/properties.json`: all projects (market, country, region, name, location, price, descriptions ES/EN, images, source).
- `img/`: resized photos (max 1100 px).

Sources: Realty2B (Inmobiliarix EXP listings) and ROES International (collaboration agreement). Prices and availability change; always confirm with the agent.
